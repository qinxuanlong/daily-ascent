# 📋 Daily Ascent (每日攀升) 需求重构与演进规划清单

> **版本**：v2.0 规划稿 (已按计划完成落地)  
> **更新时间**：2026-10-08  
> **核心演进目标**：从单次签到升级为**「时间流极简打卡 + 全功能待办管理」**，消灭多余视觉干扰，强化打卡爽感反馈，完善桌面与移动端自适应架构。  
> **技术栈要求**：**全面采用 TypeScript (TS) 进行工程化重构，禁止使用 JS**。所有组件与逻辑脚本全面拥抱 Vue 3 + `<script setup lang="ts">` 与严格类型定义。

---

## 一、 首页打卡交互与视觉极致纯粹化（Focus Mode）

### 1.1 首页内容极简化与减负
- [x] **移除冗余元素**：打卡首页剥离历史记录流水、周打卡原石矩阵等堆叠信息，拒绝信息过载。
- [x] **专注当前任务**：首页核心区域仅聚焦展示**「当前时间段待完成的打卡项卡片」**与**「核心打卡操作按钮」**。
- [x] **按时间流智能推进**：
  - 自动识别并展示当前时间点最近的未完成项。
  - 支持左右轻扫或方向键快捷预览其他未打卡项。
- [x] **全通关完成态（All-Clear State）**：
  - 当日全部待办打卡完成时，首页无缝切换为「今日目标全达成」庆典卡片（徽章辉光、通关鼓励文案），避免空状态落寞。

### 1.2 秒速打卡与强反馈动效
- [x] **消除繁琐弹窗阻断**：
  - 取消点击打卡强行弹出备注输入的交互，改为**一键瞬发打卡**。
  - 备注与心得降级为次级操作（打卡后轻点胶囊标签补充，或长按打卡按钮调出）。
- [x] **强烈动效与视听反馈（提升多巴胺奖励）**：
  - 点击打卡时触发高质感金印盖章（Stamp Impact）动画与粒子星轨爆散。
  - 配合移动端轻微触觉震动反馈（Haptic Vibration `navigator.vibrate`）与可选清脆通关音效。
  - 完成动效停留约 1 秒后，当前卡片丝滑向上划出，下一张待办卡片平滑滑入居中。

## 二、 打卡进度可视化（明确掌控学习进度）

### 2.1 顶部综合进度仪表盘
- [x] **双重进度指示**：
  - 明确展示数字指标：`已打卡 N / 待打卡 M`（如 `3 / 5`）与百分比。
  - 设计精致的极细金色流光进度条，随每次打卡动态向前推进填充。
- [x] **分段节点显示（可选）**：
  - 在进度条上以星芒刻度点标识出每个时间节点任务，清晰了解全天学习节奏。

## 三、 新增全功能待办列表页面（Task Manager）

### 3.1 待办数据体系与分类
- [x] **支持双任务类型**：
  1. **每日循环习惯**：如「每日阅读 30 分钟」、「算法刷题打卡」，每日自动重置就绪，持续累计连击天数。
  2. **当日临时待办**：支持随时随地添加的单次任务，当天完成即归档。
- [x] **任务属性字段**：
  - 标题、执行时间点（如 `09:00`、`14:30`）、分类标签（学习 / 工作 / 健身）、优先级权重、打卡心得。

### 3.2 待办列表管理交互
- [x] **时间轴模式与列表模式切换**：全量展示今日所有待办（未完成项排前，已打卡项下沉并带有划线徽标）。
- [x] **快捷管理**：
  - 支持快速新增、行内修改标题、拖拽/上下微调排序。
  - 支持一键补打卡或撤销误触打卡。

## 四、 页面架构与多端自适应布局（桌面端 vs 移动端）

### 4.1 移动端布局架构
- [x] **底部极简磨砂 Tab 导航**：
  - 包含 3 大核心视图：
    1. 🎯 **今日打卡**（极简专注模式，仅当前卡片+进度条+打卡按钮）
    2. 📝 **待办清单**（全天任务规划与编辑管理）
    3. 📜 **历程统计**（原神风打卡流水、连续连击天数、历史回顾）
  - 右上角保留极简设置图标（WebDAV 云同步与配置入口）。

### 4.2 桌面端自适应宽屏布局（响应式设计）
- [x] **解除 440px 强制窄屏限制**：
  - 在屏幕宽度 $\ge 1024\text{px}$ 时自动展开为现代化仪表盘布局。
  - **左侧工作区**：大号专注打卡卡片 + 强视觉打卡圆盘 + 今日进度总览。
  - **右侧工作区**：全量待办任务时间流清单 + 历程流水与统计热力图。
- [x] **视图模式自由切换**：
  - 桌面端右上角提供切换按钮：
    - **极简专注单栏模式（Zen Mode）**：居中窄卡片，适合悬浮窗或分屏边栏。
    - **全景工作台模式（Dashboard Mode）**：双栏全信息呈现，适合大显示器全天驻留。
- [x] **桌面端快捷键支持**：
  - `Space` 空格键：快速完成当前打卡。
  - `1` / `2` / `3`：快速在打卡、待办、历程之间切换。

## 六、 全面 TypeScript 强类型化重构与技术架构（Technical Architecture）

### 6.1 TypeScript 工程化升级
- [x] **依赖与脚手架升级**：
  - 安装 TypeScript 核心编译依赖：`typescript` (稳定版 5.7.3)、`vue-tsc`、`@types/node`。
  - 创建严格模式 `tsconfig.json`（开启 `strict: true`、`moduleResolution: "bundler"`、`target: "ES2022"`、Vue SFC 扩展支持）。
  - `package.json` 中的构建脚本改造：`"build": "vue-tsc --noEmit && vite build"`，确保无类型报错方可打包。
- [x] **全量脚本重命名与迁移至 TS 并清理死代码**：
  - `src/main.js` $\rightarrow$ `src/main.ts`
  - `vite.config.js` $\rightarrow$ `vite.config.ts`
  - `src/stores/storage.js` $\rightarrow$ `src/stores/storage.ts`
  - `src/utils/date.js` $\rightarrow$ `src/utils/date.ts`
  - `src/utils/webdav.js` $\rightarrow$ `src/utils/webdav.ts`
  - 彻底清理孤立无用的旧版组件代码与 `.js` 逻辑。
  - 所有 `.vue` 单文件组件全部升级为 `<script setup lang="ts">`，使用 `defineProps<{ ... }>()` 与 `defineEmits<{ ... }>()` 纯类型模式。

### 6.2 领域类型系统定义 (`src/types/index.ts`)
- [x] **严格的实体接口定义**：
  - `TodoItem`、`TodoType`、`CheckInLog`、`AppDataState`、`WebDavConfig`、`SyncResult`、`ActiveTab` 等。

### 6.3 存储服务层强类型重构 (`src/stores/storage.ts`)
- [x] **严格类型封装**：
  - `storage.get(): AppDataState`：带有默认初始数据的类型保护。
  - `storage.set(data: AppDataState): void`：保障落盘数据严格吻合模型。
  - 05:00 跨日检测：自动将昨日的「每日习惯」(`type === 'habit'`) 重置为未完成态，同时归档/清理昨日「临时待办」(`type === 'once'`)。

### 6.4 坚果云 WebDAV 模块 TS 重构 (`src/utils/webdav.ts`)
- [x] **网络请求与合并算法强类型化**：
  - 封装类型化响应 `SyncResult` 与增量合并。
  - 双向合并算法（Union Merge）使用泛型与唯一键 (`id` + `updatedAt`) 处理，避免任何 `any` 侵蚀。
